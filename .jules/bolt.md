## 2024-05-24 - Python 3.12+ F-String Compatibility Risk
**Learning:** Using newlines and backslashes inside f-string interpolation braces (e.g., `f"error: { \n data.get('message') \n }"`) is a syntax error in Python versions prior to 3.12 (PEP 701). Auto-formatters like `autopep8` or `black` might introduce these if configured for modern Python, causing breakages on older runtimes.
**Action:** When manually fixing long lines in f-strings, extract the variable into a local variable first (e.g., `msg = data.get('message')`), then interpolate that single variable. Avoid complex logic or newlines inside f-string braces to maintain broad Python compatibility.
